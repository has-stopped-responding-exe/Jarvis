# Design Evolution Registry

## Pattern: Tactical Reactor Dialogue Surface

### Rationale

The local design database returned no direct HUD, radar, or command-center pattern. This pattern is therefore derived from first principles: one dominant circular state instrument, asymmetrical telemetry rails, and an operator dialogue ledger. It avoids copyrighted imagery and generic dashboard card grids.

### Visual Definition

- A layered circular reactor uses independently rotating arc segments, radial ticks, a central waveform, and a state label.
- Thin diagnostic rules and corner brackets establish depth without translucent glass-card excess.
- Cyan signifies active/ready; amber signifies pending/warning; red is reserved for actionable failure.
- Dialogue is presented as an operator transcript: `YOU` and `JARVIS`, with concrete timestamps and no chat bubbles.

### Motion Consistency

- Pulse personality only: slow idle breathing, faster listening scan, converging thinking arcs, one success sweep.
- 20 FPS maximum for Canvas animation.
- Motion changes state but never communicates success without matching backend evidence.
- Full static fallback retains all labels and controls.

### Accessibility

- State is always written as text in addition to color.
- Body text remains at least 16 logical pixels at default scaling.
- Fullscreen exits with Escape; primary controls remain keyboard reachable.
- Cyan/white foregrounds maintain strong contrast against deep graphite surfaces.
